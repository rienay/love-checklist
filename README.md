# love-checklist 💕

Mobile-friendly Relationship & Commitment Questionnaire Web Application.

Aplikasi kuesioner interaktif untuk pasangan/calon pasangan guna mengenal visi, komitmen, dan kesiapan hubungan secara mendalam.

## ✨ Fitur Utama
- **Multi-Section Form**: Pertanyaan terstruktur seputar profil, komitmen, visi masa depan, dan batasan hubungan.
- **WhatsApp Direct Notify**: Tombol notifikasi instan langsung ke WhatsApp pasangan setelah pengisian selesai.
- **Deploy Ready**: Siap dijalankan di local Node.js maupun di-deploy ke Vercel (Serverless).
- **QR Code Generator**: Fitur generate QR Code untuk kemudahan akses via smartphone.

## 🚀 Menjalankan Secara Lokal
```bash
npm install
npm start
```
Buka browser di `http://localhost:3000`.
